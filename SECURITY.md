# Security policy

RockChain is an archived educational project and is not actively maintained. We still want to hear about security problems, especially leaked credentials or anything that could affect people who deploy their own copy.

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately through GitHub instead:

1. Go to the repository's **Security** tab.
2. Click **Report a vulnerability** (GitHub private vulnerability reporting).
3. Describe the problem, the affected files or versions, and how to reproduce it.

You should get an answer within a few weeks. Since the project is archived, fixes are made on a best-effort basis.

## Scope

- The code in this repository: the mobile app, `server/`, `functions/` and `firestore.rules`.
- Committed secrets of any kind.

Deployments run by third parties from this code are out of scope; report those to their operators.
